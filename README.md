# HTML Code Files — WhiteCane Academy

Welcome to the official resource repository for **WhiteCane Academy's** HTML tutorials. All code files and assets here are structured for beginner-friendly, screen-reader-accessible web development learning.

## How to Find and Use the Right File
* **Browse by Topic Name:** The files in this repository are organized by lesson topic rather than episode numbers—scan the file list above to find the topic covered in your video.
* **Listen Carefully to the Video:** Each tutorial video mentions the exact file name used in that lesson so you can locate and practice with the matching code.
* **Supporting Folders:** Any extra assets or multi-file examples referenced in the lessons are grouped inside their respective folders above.

## How to Download
* Click on any `.html` file from the list above to inspect the code directly in your browser.
* To save a file to your computer, open the file and select **Raw** or **Download raw file**, or press `Ctrl + S` on the raw view.
